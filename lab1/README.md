# Lab 1

## Scripts

### create-security-group.sh
Creates an EC2 security group and allows SSH access only from the specified public IP address (/32).

### create-instance.sh
Launches an EC2 instance using the provided AMI and security group. Prints the Instance ID.

### delete-instance.sh
Terminates the specified EC2 instance.

### delete-security-group.sh
Deletes the specified EC2 security group.
